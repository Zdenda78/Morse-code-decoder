ℹ️ About this Application

Morse Code Decoder / Trainer is a simple tool for learning, practicing and decoding Morse code. It supports keyboard input, an external dual-lever paddle connected via the 3.5 mm microphone jack.

Keyboard

  • Left Arrow & Numpad . / Del = Dot (•)
  • Right Arrow & Numpad Enter = Dash (−)
  • Spacebar = Full reset (clears everything and returns to the initial screen)

External Morse Paddle (3.5 mm jack)

  • To ensure that the Morse paddle works properly, make sure that any other external microphones are disconnected or turned off.
  • Click the Morse paddle button to enable the microphone input
  • Select your sound card / Realtek microphone when the browser asks for permission
  • Use the WPM selector (10–30 WPM) to set realistic CW keyer speed (default 20 WPM)

Other features

  • Listen & Code – Training mode: the app plays a random letter, you reply with the correct Morse code
  • Play – Plays the decoded text back in Morse code
  • Theme button (moon / sun) – Switches between dark and light mode
  • Live character preview and history of decoded text
  • The time is automatically rounded down to the exact value of the last tick after 3 seconds of inactivity.
